# 品牌语气与视觉基线

## 1. 概述与适用范围
对外文案、落地页、物料与产品内关键提示的品牌表达基线。

## 2. 标准与规范
1. **语气**：专业、克制、可信；少黑话、少夸张承诺。
2. **人称与称呼**：对用户用清晰第二人称；对内部文档用中性陈述。
3. **视觉**：Logo 安全区与最小尺寸必须遵守；主色/字体与物料规范统一。
4. **禁用**：绝对化承诺（「100%」「永不」）、恐吓式营销、未经证实的数据。
5. **多语言**：中英关键术语表一致；不混用未定义缩写。

## 3. 操作清单
- [ ] 对外物料是否经品牌/产品过目
- [ ] 截图与真实产品 UI 一致
- [ ] 法律/价格声明位置正确

## 4. 验收标准
- 去掉导航后首页仍能识别品牌，而非通用模板腔。
- 文案可被法务接受（无明显违规承诺）。

## 5. 反模式与禁忌
- 堆砌科技形容词而无具体价值。
- Logo 拉伸变形或放在杂乱背景上。

## 6. 示例
优：「服务端分页，默认每页 20 条，支持高级筛选。」  
劣：「赋能极致丝滑的智能体验革命。」
