# 跨境 Listing 优化要点

## 1. 概述与适用范围
适用于 Amazon / 同类平台的商品详情页（Listing）基础优化：标题、五点、主图、A+、关键词。

## 2. 标准与规范
1. **标题**：核心关键词靠前，可读通顺，避免无意义堆砌与违禁词。
2. **五点描述**：每点一个卖点或差异；量化优先（尺寸、材质、兼容性）。
3. **主图**：白底合规；主体占比足够；系列图展示场景/细节/尺寸对比。
4. **A+ / 视频**：提升停留与转化；信息与五点一致，不矛盾。
5. **关键词**：后台 Search Terms 覆盖同义与场景词；定期看搜索词报告迭代。
6. **合规**：声明、认证、安全警示按类目要求展示。

## 3. 操作清单
- [ ] 竞品标题/五点/价格带调研
- [ ] 主图与类目规范自检
- [ ] 关键词与否定词周回顾
- [ ] 差评中的 Listing 相关问题归因并改版

## 4. 验收标准
- 主图与标题在移动端首屏可读。
- 无平台驳回风险的违禁表述。

## 5. 反模式与禁忌
- 夸大功效、医疗宣称、假评诱导。
- 主图文字墙导致审核或体验差。

## 6. 示例五点骨架
材质/工艺 → 核心功能 → 使用场景 → 兼容/规格 → 售后与包装差异。
