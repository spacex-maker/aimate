# 增长飞轮与留存

## 1. 概述与适用范围
指导获客 → 激活 → 留存 → 变现（及推荐）闭环的设计与复盘。适用于产品运营与增长实验。

## 2. 标准与规范
1. **先定北极星**：单一主指标 + 2–3 个护栏（如质量、投诉、成本）。
2. **漏斗拆解**：每步有定义、分母分子口径、周环比看板。
3. **实验纪律**：假设 → 设计 → 对照 → 结论 → 全量/放弃；禁止同时改过多变量。
4. **渠道**：记录 UTM/来源；周复盘 CAC 与边际 ROI，而不是只看曝光。
5. **留存**：区分新客/老客；沉默唤醒策略必须可关停、可频控。

## 3. 操作清单
- [ ] 北极星与护栏已书面确认
- [ ] 关键漏斗步骤口径产品/数据双签
- [ ] 活动有对照或至少前后对比窗口
- [ ] 亏损渠道有止损线

## 4. 验收标准
- 任意增长活动能回答：目标指标、成本上限、停止条件、学习沉淀。

## 5. 反模式与禁忌
- 用短期补贴堆 DAU 却损害留存与口碑。
- 无归因的「感觉有效」就加预算。

## 6. 示例
「激活」定义为：注册 24h 内完成首次有效会话（会话时长 ≥ X 或完成关键动作 Y）。
