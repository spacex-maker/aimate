# 渠道组合策略

## 1. 概述与适用范围
付费、自然与合作渠道的组合权重、追踪与周复盘。

## 2. 标准与规范
1. **角色**：付费补量；自然流量建护城河；合作拓展信任与场景。
2. **追踪**：统一 UTM；落地与转化事件一致。
3. **决策**：周会看 CAC 与 LTV（或贡献利润）比，而不是只看曝光与点击。
4. **止损**：渠道级预算上限与观察期；无效及时降量。
5. **协同**：内容、投放、销售线索交接有 SLA。

## 3. 操作清单
- [ ] 渠道清单与负责人
- [ ] UTM 规范文档
- [ ] 周报：花费、获客、质量、留存/付费

## 4. 验收标准
- 能解释本月预算在各渠道间的分配理由。
- 自然与付费不互相「抢」同一归因而不加注释。

## 5. 反模式与禁忌
- 砍掉自然内容只砸付费。
- 无质量指标的纯量增长。

## 6. 示例
「合作渠道线索 48h 内跟进；超时自动回流公海并记渠道质量分。」
