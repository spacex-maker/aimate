# 模型评估清单

## 1. 概述与适用范围
机器学习/排序/分类模型上线前的离线评估与上线门槛。适用于推荐、风控、检索等场景的通用纪律。

## 2. 标准与规范
1. **任务匹配指标**：分类看 Precision/Recall/F1；排序看 AUC/NDCG/MAP；回归看 MAE/RMSE；业务还可加校准度。
2. **切片**：必须按新老客、地域、设备、流量来源等关键切片，防整体好看局部崩盘。
3. **数据泄漏**：时间切分优先；禁止用未来信息训练。
4. **上线门槛**：影子流量 / 小流量；设回滚阈值（业务指标与系统指标双护栏）。
5. **监控**：线上分布漂移、延迟、空结果率、人工反馈。

## 3. 操作清单
- [ ] 离线指标与基线对比表完整
- [ ] 切片无显著回退或已解释可接受
- [ ] 回滚开关与负责人明确
- [ ] 特征与标签生成可复现

## 4. 验收标准
- 能回答：相对线上基线提升多少、在哪些切片更差、最坏情况如何回滚。

## 5. 反模式与禁忌
- 只报整体 AUC 上涨就全量。
- 训练集与验证集随机切分导致时间泄漏。
- 无业务指标只看机器学习指标。

## 6. 示例门槛
「核心转化护栏不下降 >0.5%；P95 延迟不增 >20ms；否则自动回滚。」
