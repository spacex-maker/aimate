# 创业项目尽调清单

## 1. 概述与适用范围
用于种子轮至成长期项目的投资尽职调查。目标是快速判断「值不值得投、按什么条款投、主要风险在哪」，并形成可复核的投决材料。

## 2. 尽调维度
1. **团队**：创始人履历与互补性、股权与 vesting、关键岗位缺口、过往创业/退出记录。
2. **市场**：TAM/SAM/SOM 口径是否一致、增长驱动、竞争格局与替代品、监管边界。
3. **产品与技术**：核心差异化、壁垒（数据/网络/牌照/工艺）、路线图可信度、客户验证。
4. **商业与财务**：收入模型、毛利结构、获客成本与留存、历史账本与预测假设。
5. **法务与合规**：公司主体、知识产权归属、重大合同、劳动与税务、行业牌照。
6. **交易与结构**：本轮用途、现有投资人、期权池、对赌/回购、控制权与信息权。

## 3. 操作清单
- [ ] 明确本轮目的：验证产品 / 扩张 / 并购预备，资金用途可追踪
- [ ] 核心假设写清「可证伪条件」与验证时间窗
- [ ] 红旗清单单独汇总（诉讼、关联交易、数据权属、集中客户）
- [ ] 引用材料标注来源与日期，避免口头口径入投决

## 4. 验收标准
- 投决材料能在 1 页内说清：投什么、为什么现在、主要风险、退出路径。
- 财务预测关键假设可回溯到客户访谈或合同证据。

## 5. 反模式与禁忌
- 只看故事与 PPT，不核对数据口径与合同。
- 用「赛道很大」代替可服务市场与获客路径。
- 忽视创始人股权激励与关键人离职条款。

## 6. 示例验收句
「尽调报告列明前三大客户收入占比、续约率与合同到期日；若单一客户超 40%，须附流失情景与对冲方案。」
