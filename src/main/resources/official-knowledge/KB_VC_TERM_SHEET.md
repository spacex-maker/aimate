# 投资条款要点

## 1. 概述与适用范围
用于解释与草拟风险投资常见条款清单（Term Sheet / SPA 关键条款）。面向非律师投资人与创业者对齐「钱怎么进、权怎么分、出事怎么处理」。

## 2. 核心条款
1. **估值与价格**：投前/投后估值、本轮金额、价格计算（含 SAFE/可转债转换）。
2. **股权与期权池**：新老股结构、期权池扩容由谁稀释。
3. **清算优先权**：倍数、参与/非参与、与普通股的分配顺序。
4. **反稀释**：加权平均 vs 全棘轮；触发情形与例外。
5. **治理**：董事会席位、保护性事项（否决权清单）、信息与检查权。
6. **转让与退出**：优先购买、共同出售、拖售、IPO/并购锁定期。

## 3. 操作清单
- [ ] 条款表用「中性语言」写清：触发条件、计算公式、例外
- [ ] 保护性事项控制在真正影响控制权/重大资产的范围
- [ ] 同步核对公司章程、股东协议与历史轮次是否冲突
- [ ] 给创业者一份「条款影响一页纸」（稀释、清算、决策）

## 4. 验收标准
- 创始人与投资人能各自复述清算与反稀释情景，数字一致。
- 律师能据此起草，无需再口头补关键商业意图。

## 5. 反模式与禁忌
- 堆砌「市场惯例」却不写具体倍数与参与方式。
- 保护性事项过宽，导致日常经营无法运转。
- 忽略员工期权池扩容对创始人稀释的实际影响。

## 6. 示例验收句
「本轮投后估值 ¥X、投资额 ¥Y；1x 非参与清算优先；加权平均反稀释；董事会 5 席中投资人 1 席；重大融资/出售公司须投资人书面同意。」
