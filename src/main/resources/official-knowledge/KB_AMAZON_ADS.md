# 亚马逊广告入门

## 1. 概述与适用范围
Amazon Sponsored Products 等广告的基础投放框架：结构、收词、出价与 ACOS 目标。

## 2. 标准与规范
1. **目标**：先定目标 ACOS / TACOS 与阶段（新品收词 vs 成熟控本）。
2. **结构**：自动广告收词 → 手动广泛/词组 → 精确；否定词持续清理。
3. **预算**：库存紧张时降预算，避免断货差评与无效花费。
4. **创意与落地**：广告指向的 Listing 转化差时先修页面再加预算。
5. **节奏**：新品可略宽收词；稳定后收缩无效词、加投高效精确词。

## 3. 操作清单
- [ ] 活动命名规范（站点-SKU-目标-日期）
- [ ] 每周搜索词报告：加投 / 否定
- [ ] 对照自然位与广告位转化，避免只看点击
- [ ] 大促前预算与库存联审

## 4. 验收标准
- 能说清每个活动的目标 ACOS 与是否达标。
- 否定词库有维护记录，无长期烧预算的垃圾词。

## 5. 反模式与禁忌
- 无目标 ACOS 盲目提高出价。
- 断货仍投放。
- 自动与手动大量重复词互抢且不分析。

## 6. 示例
「SKU-A 新品 14 天：自动收词，目标 ACOS ≤35%；其后精确词目标 ≤25%。」
