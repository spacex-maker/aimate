# 跨境供应链协同清单

## 1. 概述与适用范围
选品落地后的采购、质检、头程、海外仓与滞销处理协同。

## 2. 标准与规范
1. **下单前**：确认 MOQ、交期、付款方式、质检标准、包装规范、违约条款。
2. **质检**：抽样标准与不合格处理（返工/让步/退货）书面化。
3. **头程**：时效、旺季加价、报关资料提前准备；追踪节点异常升级。
4. **海外仓**：按周转天数备货；安全库存与滞销阈值分开管理。
5. **异常**：断货、质损、甩柜有预案与责任人。

## 3. 操作清单
- [ ] 供应商档案：联系人、产能、历史质量
- [ ] 在途与在库可视；SKU 维度周转
- [ ] 滞销触发清仓/停产决策会

## 4. 验收标准
- 任意 SKU 能答：在产、在途、在库、预计可售天数。
- 质检不合格有闭环记录。

## 5. 反模式与禁忌
- 口头改交期无邮件/系统记录。
- 旺季临发才发现资料不全。
- 忽略退货入库对库存准确性的影响。

## 6. 示例
「周转天数 = 在库可售 / 近 14 日日均出库；低于安全天数触发补货评审。」
