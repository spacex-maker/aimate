# 设计系统与组件规范

## 1. 概述与适用范围
定义界面设计的间距、字体层级、颜色语义与组件状态，保证跨页面一致性与可访问性。

## 2. 标准与规范
1. **网格**：默认 8pt 间距体系；页面边距与卡片内边距成比例。
2. **文字层级**：主文 / 次文 / 弱文三级对比，避免满屏同级字重。
3. **颜色语义**：主色用于关键行动；危险操作用警示色；成功/信息色不滥用装饰。
4. **组件状态**：至少覆盖 default / hover / focus / disabled / error / loading。
5. **表单**：标签清晰；错误文案贴近字段；禁止仅靠颜色传达错误。
6. **无障碍**：对比度达标；可见焦点环；图标按钮有 aria-label；可读替代文本。

## 3. 操作清单
- [ ] 新组件是否复用设计令牌（色/字号/圆角）而非魔法数
- [ ] 暗色主题下对比是否仍可读
- [ ] 键盘焦点顺序是否合理

## 4. 验收标准
- 同一组件在列表、弹层、表单中表现一致。
- 色盲友好：不只靠红绿区分状态。

## 5. 反模式与禁忌
- 每页自创一套圆角/阴影。
- 禁用态仍可点击或看不清。
- 弹层无关闭与遮罩点击行为约定。

## 6. 示例
主按钮：实心主色；次按钮：描边；危险：警示色且二次确认。
