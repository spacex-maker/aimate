# 合同审查清单

## 1. 概述与适用范围
商务/采购/合作类合同的基础法律风险审查要点。复杂案件仍需法务正式意见。

## 2. 标准与规范
1. **主体**：名称、证件号与签章权限一致；分公司/个人签约注意能力边界。
2. **标的与交付**：做什么、交付物、验收标准、时间表清晰。
3. **价款与支付**：金额、税、支付节点、发票、逾期利息。
4. **违约与解除**：违约金是否过高/过低；单方随意解约条款标红。
5. **知识产权与保密**：成果归属、许可范围、保密期限。
6. **争议解决**：管辖/仲裁、适用法律、语言版本（涉外）。
7. **责任限制**：无限责任、间接损失排除是否可接受。

## 3. 操作清单
- [ ] 对照本清单逐条批注
- [ ] 高风险条款汇总给决策人
- [ ] 附件（SOW、价目、SLA）与主文一致

## 4. 验收标准
- 审查意见可执行：改哪条、为何改、不改的风险。
- 无「已阅」无实质意见的橡皮图章。

## 5. 反模式与禁忌
- 只看价格不看验收与 IP。
- 口头承诺覆盖书面条款。

## 6. 示例标红
「乙方可随时提前 3 日书面解约且不承担违约责任」→ 需对等或删除。
