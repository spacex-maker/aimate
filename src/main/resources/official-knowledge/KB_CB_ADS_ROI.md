# 跨境投放 ROI 框架

## 1. 概述与适用范围
跨渠道（平台内广告、信息流、联盟等）预算分配与归因纪律。

## 2. 标准与规范
1. **统一目标**：以贡献利润或目标 ROI 为主，曝光为辅。
2. **归因**：窗口期与平台报表对齐；跨渠道避免重复算转化。
3. **预算**：按边际 ROI 分配；设渠道止损线与观察期。
4. **创意**：素材疲劳要轮换；落地页与素材卖点一致。
5. **复盘**：周会看 CAC、ROI、退货率、库存，不只看点击。

## 3. 操作清单
- [ ] 各渠道 UTM/追踪参数规范
- [ ] 止损线写入投放表
- [ ] 亏损渠道有关停或降量记录

## 4. 验收标准
- 能解释本周预算增减的数据依据。
- 归因口径文档与报表一致。

## 5. 反模式与禁忌
- 只优化点击成本忽视利润与退货。
- 多渠道最后点击互相抢功导致错误加预算。

## 6. 示例止损
「观察 5 日，ROI < 目标 70% 且花费 > 日预算 3 倍 → 暂停并复盘素材/落地。」
