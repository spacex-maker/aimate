# TikTok Shop 内容与直播

## 1. 概述与适用范围
短视频带货与直播间转化节奏、人设与合规话术。

## 2. 标准与规范
1. **短视频**：前 3 秒给钩子（痛点/结果/冲突）；中段演示；结尾明确行动点。
2. **人设**：稳定可识别，人设与选品一致，避免频繁换风格。
3. **SKU**：少而精；主推款有清晰卖点与价格锚点。
4. **直播节奏**：引流 → 演示 → 限时利益 → 逼单 → 答疑循环；场控与库存同步。
5. **合规**：禁用绝对化承诺与违禁功效宣称；价格与赠品以系统设置为准。

## 3. 操作清单
- [ ] 脚本/提纲：钩子、卖点、异议处理
- [ ] 测品与测素材：保留数据再加预算
- [ ] 直播复盘：停留、点击、转化、退货原因

## 4. 验收标准
- 主推款在视频与直播话术一致。
- 无平台警告级违规话术。

## 5. 反模式与禁忌
- 只靠低价无差异，导致退货与劣质评论。
- 虚假倒计时、假库存制造焦虑。

## 6. 示例钩子
「还在为 XX 多花三倍时间？这个 30 秒流程给你看。」
