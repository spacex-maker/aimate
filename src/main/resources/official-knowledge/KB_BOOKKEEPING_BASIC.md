# 会计核算基础

## 1. 概述与适用范围
面向非财务同事的基础核算概念与费用报销纪律，便于与财务协作。不替代正式会计准则培训。

## 2. 标准与规范
1. **等式**：资产 = 负债 + 所有者权益。
2. **借贷**：资产/费用增加记借方；负债/权益/收入增加记贷方（入门记忆，以财务制度为准）。
3. **权责发生制**：收入费用按归属期确认，不只按收付现。
4. **报销**：票据齐全、事由清晰、审批流完整；跨期费用按要求摊销。
5. **科目**：使用公司科目表，禁止随意自造科目名入账。

## 3. 操作清单
- [ ] 报销单附件：发票、行程/合同依据
- [ ] 项目/部门归属正确，便于成本核算
- [ ] 大额预付/押金单独跟踪

## 4. 验收标准
- 财务能仅凭单据完成入账，无需反复追问事由。
- 月结无明显「暂挂无法核销」堆积。

## 5. 反模式与禁忌
- 白条入账、阴阳发票。
- 个人消费与公司费用混同。

## 6. 示例
「年度软件订阅 12 个月费用，按月摊销，而非一次性全部计入当月费用（以公司政策为准）。」
