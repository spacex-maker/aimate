# 内容日历与选题

## 1. 概述与适用范围
内容营销的栏目节奏、选题来源、生产复用与效果复盘。

## 2. 标准与规范
1. **栏目固定**：周更/双周更写进日历；负责人与截止日明确。
2. **选题**：对齐用户痛点与产品卖点；来源含客服问题、销转异议、数据洞察。
3. **形态复用**：长文可拆短视频脚本、社群金句、邮件摘要。
4. **发布后**：看完读/完播/转化；低效选题淘汰并记录原因。
5. **品牌一致**：语气与视觉遵循品牌基线；禁用违规承诺。

## 3. 操作清单
- [ ] 下月日历已排到负责人
- [ ] 每篇有目标指标（认知/信任/转化）
- [ ] 素材库可检索复用

## 4. 验收标准
- 任意选题能说清：给谁看、解决什么问题、期望行为。
- 连续两期低效有明确停更或改版决策。

## 5. 反模式与禁忌
- 为发而发、与产品无关的热点硬蹭。
- 无数据复盘的「感觉挺好」。

## 6. 示例日历字段
