# 业务指标字典

## 1. 概述与适用范围
统一核心业务指标口径，避免「同名不同义」。变更必须版本化。

## 2. 标准口径（示例，可按产品裁剪）
1. **DAU**：自然日内至少一次有效会话的独立用户数。「有效」需定义（如登录成功或完成关键动作）。
2. **次日留存**：D0 新用户集合中，在 D1 仍活跃的比例；分母为 D0 新用户。
3. **转化率**：漏斗相邻步骤的完成比；步骤定义需产品/数据双方签字。
4. **付费相关**：订单以「支付成功」为准还是「履约完成」为准必须写死；退款是否回滚指标要说明。

## 3. 操作清单
- [ ] 指标有负责人与文档链接
- [ ] 看板注明统计时区与刷新频率
- [ ] 口径变更有版本号与生效日期

## 4. 验收标准
- 任意两个分析师按文档可算出误差可接受的同一数字。
- 口径变更后历史对比有注解，不默默改过去曲线。

## 5. 反模式与禁忌
- 口头口径、每人一套 SQL。
- 用曝光冒充活跃，用注册冒充激活。

## 6. 示例变更记录
`v1.2 2026-03-01：有效会话改为「时长≥30s 或完成发送消息」。`
